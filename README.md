# Calculadora em Ruby

## Sobre o projeto

Este projeto consiste em uma calculadora desenvolvida em Ruby para praticar os fundamentos da lógica de programação e a construção de programas interativos via terminal.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Entrada de números inteiros e decimais
- Validação para evitar divisão por zero

## Tecnologias utilizadas

- Ruby
- Git
- GitHub

## Como executar

1. Instale o Ruby em sua máquina.
2. Clone este repositório ou baixe os arquivos.
3. Abra o terminal na pasta do projeto.
4. Execute o comando:

```bash
ruby calculadora.rb
```

## Objetivo

Praticar estruturas condicionais, operadores matemáticos, entrada de dados e validações, fortalecendo minha base em programação Ruby.

Este projeto faz parte da minha jornada de aprendizado e evolução como desenvolvedor Back-end Ruby.
